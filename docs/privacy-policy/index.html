Privacy Policy for All Links Extractor

Last updated: November 7, 2026

All Links Extractor is a Chrome extension that helps users extract, audit, organize, save, and export links from web pages, selected text, embedded page assets, and open browser tabs.

This policy covers the Chrome extension. You can use its features without creating an account.

Data We Handle

The extension processes content from pages you scan and from supported tabs when you enable optional auto-capture. Auto-capture is off by default. Data the extension may process includes:

  • Page links and URLs
  • Anchor text
  • Page title and source URL
  • Image, video, audio, document, iframe, canonical, and hreflang URLs
  • Selected text when the user chooses selected-text extraction
  • Link audit metadata such as link type, domain, duplicate count, health status, and preview information
  • Sitemap URLs and metadata from online sitemaps, pasted XML, or files you select

How Data Is Used

The extension uses this data to provide features such as:

  • Extracting links from pages
  • Showing link audit results
  • Filtering, sorting, grouping, and analyzing links
  • Saving extraction history locally
  • Exporting links and reports
  • Checking link health when requested
  • Fetching page previews when requested
  • Discovering, reading, filtering, and exporting sitemaps
  • Comparing saved extraction sessions
  • Highlighting extracted links on the source page
  • Supporting optional auto-capture if the user enables it

Data Storage

The extension saves extracted links, history, settings, cached previews, and saved audit data in local Chrome extension storage. Exported files are saved through Chrome's downloads feature.

The extension stores a local count of successful manual scans and whether it has already shown the optional review and support prompts. It uses this information to show each prompt once in the Audit dashboard. It does not send the count or prompt state to us or to the sites linked in the prompts.

We do not operate a server for collecting extension data.

Data Sharing

We do not sell, rent, or trade user data. The extension does not send extracted data to a developer-operated server or use it for advertising, profiling, or remote analytics.

Network Requests

When you run link health checks, fetch previews, crawl pages, or discover or read online sitemaps, the extension sends requests directly from your browser to the relevant websites. Sitemap discovery may request robots.txt and common sitemap locations, and online sitemap reading may fetch child sitemaps. Receiving sites can see ordinary request information such as your IP address and the requested URL.

The extension processes pasted sitemap XML and imported sitemap files locally. Importing a local sitemap index does not automatically fetch its child URLs.

Reviews, Support, and Feedback

If you choose to leave a review, support development, or submit feedback on GitHub, the corresponding third-party site opens in your browser. The extension does not send your scan results with those links. Information you choose to submit is handled by the Chrome Web Store, Buy Me a Coffee, or GitHub under its own privacy practices. GitHub issues in the linked repository are public.

Remote Code

All JavaScript, CSS, HTML, and icons are packaged inside the extension. The extension does not download or execute remote JavaScript code.

Permissions

The extension requests permissions only for its stated functionality:

  • scripting: to extract and highlight links on pages the user scans
  • activeTab: to access the current tab after user action
  • tabs: to identify supported tabs and support all-tabs extraction or optional auto-capture
  • storage: to save settings, extracted links, history, previews, and reports locally
  • downloads: to export reports and link files
  • contextMenus: to provide right-click extraction actions
  • Host permissions: to extract and audit links from websites the user chooses to scan

Limited Use Statement

The use of information received from Chrome APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

User Control

You can delete individual extraction sessions or clear saved history from the History page, and turn off auto-capture in Settings. Removing the extension clears its local extension storage. You can manage exported files separately on your device.
